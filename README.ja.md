OpenAIの *The periodic spin-one Haldane gap* における空間モーメント表現と初期純度評価を前提として、結合定数 $J=1$ の全ての偶数長 $L\ge2304$ で

$$\gamma_L>0.0047$$

が従うことを示します。極限については $\liminf\gamma_L\ge0.0047$ です。原論文の下限 $\log(20)/784\simeq0.00382109$ に対して約23%の改善です。既存の証明に含まれる余裕を詰めた定量的な拡張であり、Haldane予想の独立解決や最適定数を主張するものではありません。

改善に必要なのは、純度欠損の上界に対する5回の追加更新、5区間の評価、残る全ての長さの一括評価です。論文に証明を、`verify_gap_improvement.py` に短い検証を収録しています。追加の数値入力は必要ありません。

```sh
python3 verify_gap_improvement.py
```

Python標準ライブラリだけで実行できます。合否を決める不等式は全て有理数で評価します。表示用の小数値を証明には使用しません。
