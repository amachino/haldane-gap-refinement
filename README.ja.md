[論文PDF](paper/note.pdf) · [英語README](README.md) · [先行研究調査と位置づけ](PRIOR_ART.md)

OpenAIが公開済みの二つの論文の命題を組み合わせ、結合定数 $J=1$ の周期スピン1 Heisenberg鎖について、次の明示的な帰結を取り出しました。

$$
\gamma_L>\frac{\log(125/39)}{49}>0.02377
\qquad\text{全ての偶数長 }L\ge120.
$$

正確な定数は約 $0.023770450840258259$ です。偶数長を通じた極限については $\liminf\gamma_L\ge\log(125/39)/49$ が従います。元論文の解析的結果と有限入力の正しさを前提とする条件付きの下限です。

**旧版の比較範囲を訂正しました。** Version 1.0の $0.0047$ は周期鎖論文に明記された値を約23%改善します。しかし、関連論文まで含めた既存資料からは、より強い下限が直接従います。初回の比較では、この関連論文の周期鎖評価を見落としていました。旧版の証明・検証記録は保持し、新しい主結果との関係を明記しています。

| 結果 | ギャップの下限 | 成立する長さ |
|---|---|---|
| 周期鎖論文に明記された値 | $\log(20)/784\approx0.00382109$ | 全ての偶数 $L\ge2304$ |
| 本repoのVersion 1.0 | $0.0047$ | 全ての偶数 $L\ge2304$ |
| 二論文からVersion 1.1で取り出した帰結 | $\log(125/39)/49\approx0.02377045$ | 全ての偶数 $L\ge120$ |

全て同じ周期鎖、同じ規格化での比較です。新しい定数は旧版の約5.06倍で、適用範囲も広がります。

## 導出と帰属

*A boundary-field gap for the spin-one Heisenberg chain* の命題3.4には、**境界磁場のない周期鎖**について

$$1-S(120,49)\le0.052,\qquad1-T(240,49)\le0.052$$

という評価が含まれます。これを *The periodic spin-one Haldane gap* の命題4.3に、$n_0=120$、逆温度 $\beta_0=49$、$u_0=13/250$、$C=6$ として代入します。定理の条件を満たし、$r=Cu_0=39/125$ から上記の下限と基底状態の一意性が従います。逆温度49は関連論文の $b_2$ です。

初期評価を作る議論とギャップ定理はOpenAIの既存成果です。今回の寄与は、二つの命題を結びつけた明示的な帰結、その有理数検証、および比較の訂正です。この具体的な定数を明記した先行報告は調べた範囲では見つかっていませんが、優先権・最適性・Haldane予想の独立解決は主張しません。物理的なギャップの推定値でもありません。
