## 奇数長を含める証明

以下にはVersion 1.2の、全ての整数 $L\ge120$ に対する下限 $\log(125/39)/49$ の導出を保持しています。

周期鎖論文の命題3.1には、全ての整数 $L\ge4$ に対する $Z_L(\beta)=\sum_i\mu_i(\beta)^L$ という符号付きのトレース公式があります。関連する境界磁場論文の命題3.4は、最大絶対値の固有値が正で一意であること、その温度間の比、および周期鎖の純度評価を与えます。正の固有値であることの証明は分配関数の正値性を使っており、奇数鎖のギャップを仮定していません。

$n_k=120\,2^k$、$\beta_k=49\,2^k$、$u_k=\frac16(39/125)^{2^k}$ とします。要点は、**二つの温度で同じ偶数の基準長 $n_k$ を使う**ことです。

$$
S(n_k,2\beta_k)=\frac{S(n_k,\beta_k)^2T(2n_k,\beta_k)}{T(n_k,\beta_k)^2}
\ge(1-u_k)^3\ge1-3u_k.
$$

ここから、支配的な固有値以外の絶対値の寄与を両温度で抑えられます。長さを任意の整数 $L\ge n_k$ に増やしてもこの評価は維持され、負の固有値が奇数乗で生む負の寄与も制御できます。論文では、全ての整数 $n_k\le L\le2n_k$ について

$$T(L,\beta_k)\ge1-\frac92u_k>\frac12$$

を証明し、基底状態の一意性とギャップ下限を導きます。これらの区間は全ての整数 $L\ge120$ を覆います。偶数専用の命題を奇数にそのまま適用したのではなく、既存のスペクトル評価を使う新たな導出を加えています。追加の熱計算や変分計算は不要です。
